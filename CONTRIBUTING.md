# Contributing to FHIR Converter (Service Well AB)

We welcome contributions, feedback, and suggestions!  
By participating in this project, you agree to respect the project's license and code of conduct.

---

## How to Contribute

- Fork the repository.
- Create a feature branch (`feature/your-feature-name`).
- Make your changes.
- Submit a pull request with a clear description of your changes.

Please ensure that:
- Code follows the project's coding style.
- Unit tests are added where applicable.
- All terminology dependencies (ConceptMaps, CodeSystems) are declared properly in `flc-config.yaml`.
